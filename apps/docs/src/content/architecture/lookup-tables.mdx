# Lookup Tables

Lookup tables define the controlled taxonomies used by mapping tables, production dimensions, reporting views, filters, and application picklists.

This inventory reflects the latest Dataform DDL in `packages/dataform` and its mirror in `REVREBEL/Metrics-Dataform`.

# Known normalization gaps

- `lkp_company.industry` uses a text relationship to `lkp_industry.industry` rather than an industry code.
- `lkp_agency.rate_type` is a text field and does not use `ratetype_code`.
- Event lookups use `insert_timestamp STRING`, while most lookup tables use `insert_date DATE` and `updated_date DATE`.
- No current Dataform DDL exists for `lkp_roomtype`, despite an app-registry dependency on that name.
- BigQuery does not enforce these relationships as physical foreign keys; they are semantic contracts validated by Dataform, ingestion, and application logic.
