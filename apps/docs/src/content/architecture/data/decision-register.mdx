# Data Architecture Decision Register

This interim register prevents unresolved data-model questions from being presented as implemented architecture. REV-72 owns the full decision-register workstream.

| Decision | Current status | Current implementation |
|---|---|---|
| Separate `map_channel` table | **UNRESOLVED** | Channel mapping currently uses `map_source.channel_code` |
| Agency source-value mapping | **UNRESOLVED** | `lkp_agency` exists; `map_agency` does not |
| Canonical market taxonomy | **UNRESOLVED** | `map_market` does not exist |
| Room taxonomy normalization | **UNRESOLVED** | Room attributes remain embedded in `map_roomtype`; no `lkp_roomtype` exists |
| `map_source_metric` responsibility | **UNRESOLVED** | No current Dataform DDL |
| Property/source identifier mapping | **PLANNED** | `map_hotel` is a registry concept; no current Dataform DDL |
| Global versus property-specific mappings | **UNRESOLVED** | Current implemented mappings are property-scoped |
| Draft mapping publication workflow | **UNRESOLVED** | Application-database and publication boundary still requires approval |
| Canonical `dim_segment` physical schema | **UNRESOLVED** | `00_create_core_tables.sqlx` and `05_create_segment_tables.sqlx` define different shapes with `CREATE TABLE IF NOT EXISTS` |
| Pace table prefix migration | **UNRESOLVED** | Current measurable pace tables use `snap_`; naming standards prefer grain-specific `fact_` for new work |
| Canonical actual fact families | **PLANNED** | No current Dataform tables with the `fact_` prefix and no implemented actual fact family |
| Snapshot-table partitioning and clustering | **UNRESOLVED** | Staging tables declare layouts; `snap_pace_*` creation statements do not |
| Pickup dataset name | **UNRESOLVED** | `metrics_pickup` is a documentation target only; no dataset exists in current Dataform |
| Pickup source grain | **UNRESOLVED** | Final use of `source_code`, `subsource_code`, `channel_code`, or a durable source key is not approved |
| Pickup numeric value type | **UNRESOLVED** | Long/narrow `metric_value` is approved conceptually; physical numeric type is not implemented |
| Non-day pickup comparisons | **UNRESOLVED** | Fixed rolling windows use planned `window_days INT64`; prior-year and cycle comparisons need a separate type decision |
| Room-class pickup family | **UNRESOLVED** | Current pace contains room-class snapshots, but the approved pickup family currently names property, segment, source, and room type |
| Metric-definition persistence model | **UNRESOLVED** | `packages/metrics` is the approved package boundary, but no active package or application-database schema currently stores governed definitions |
| Executable formula representation | **UNRESOLVED** | Current formulas are implemented in Dataform SQL and compatibility DuckDB SQL; no published formula contract exists |
| Metric publication and approval roles | **UNRESOLVED** | Linear assigns core metric management to REVREBEL users, but workflow states, approver roles, and permissions are not implemented |
| Metric version and effective-date behavior | **UNRESOLVED** | No current versioned metric registry governs historical consumers |
| Comparison and variance taxonomy | **UNRESOLVED** | Compatibility code calculates differences and attainment, but metric names do not yet distinguish amount, rate, percentage, percentage points, and index consistently |
| ALOS denominator and reservation treatment | **UNRESOLVED** | No governed reservation-count or stay-count denominator exists in current Dataform outputs |
| Metric mart storage shape | **UNRESOLVED** | Decision required on metric-code rows, named columns, or a governed combination in serving marts |
| Ingestion orchestration and scheduling | **UNRESOLVED** | Dataform creates warehouse structures but no canonical file watcher, API extraction service, or scheduler is implemented |
| Durable source-report and file-load identity | **PLANNED** | Staging stores descriptive report and file fields; no implemented load key connects rows to a control registry |
| Source-report metadata population | **UNRESOLVED** | `dim_source_report` exists but current Dataform does not populate it or join staging rows through `source_report_id` |
| Freshness service levels | **UNRESOLVED** | No approved cadence, grace period, warning threshold, or blocking threshold matrix |
| Operational refresh-history model | **PLANNED** | No current table records run status, row counts, source observation range, assertion outcomes, or retries |
| Pace source coexistence in unique grain | **UNRESOLVED** | Candidate pace keys may require source application, report, or load identity when multiple sources coexist |
| Assertion severity and publication gate | **UNRESOLVED** | Current Dataform definitions contain no native assertions or consolidated blocking workflow |
| Mapping coverage thresholds | **UNRESOLVED** | No approved warning or failure threshold for unmapped source values |

Confirmed decisions should be removed from this register and moved into the canonical subject documentation when Linear approves them or implementation establishes them.
