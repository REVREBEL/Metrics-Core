## Source ownership

Use the following authority order when these sources differ:

1. Linear defines product intent, approved terminology, and initiative or project boundaries.
2. Repository code defines the current application implementation.
3. Dataform defines the current warehouse schema, dependencies, mappings, lookups, and assertions.
4. Documentation explains the system but must be reconciled against the sources above.
5. Registries and fixtures are application scaffolding unless current implementation confirms otherwise.

Documentation must distinguish:

```text
IMPLEMENTED
PLANNED
COMPATIBILITY
DEPRECATED
UNRESOLVED
```

## Existing-page disposition

### Retain for historical and implementation reference

The following documents remain useful for historical or implementation context. They are not authoritative when a canonical page listed above supersedes their policy or terminology.

- `architecture/column-naming-standards.mdx`
- `architecture/prefix_standards.mdx`
- `architecture/source-file-ingestion-model.mdx` — historical design reference superseded by the canonical source, lineage, and validation pages
- `core/segment-model.mdx`
- `core/source-channel-rate-model.mdx`
- `core/roomtype-model.mdx`
- domain documentation under `rms`, `demand`, and `google-analytics`

These pages must not be treated as independent confirmation when they repeat prior architecture work.

### Rewrite or split

- `architecture/table-architecture.mdx`

This page currently mixes confirmed design decisions with physical-object claims. The canonical dimension, fact, pickup, and reporting catalogs now own those definitions. The older page should be retained only as conceptual or historical source material until it is rewritten.

### Keep as historical documentation

- `development/app-migration/01-legacy-application-audit.md`
- historical route, iframe, registry-adapter, or browser DuckDB migration material

Historical pages should receive explicit banners when they are next edited. They are evidence of prior implementation, not the current architecture authority.
