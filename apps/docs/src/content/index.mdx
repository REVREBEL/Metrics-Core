# Metrics Library

## Metrics Platform

Metrics is REVREBEL’s internal business intelligence and analytics platform for centralizing, standardizing, and analyzing hospitality data across operational systems.

PMS exports, CRS reports, RMS forecasts, booking-engine data, pace reports, spreadsheets, and vendor systems all structure information differently. Metrics provides a shared reporting framework that turns those sources into consistent operational intelligence for forecasting, revenue strategy, distribution analysis, performance reporting, and decision-making.

## Documentation standards

This library maintains the standards used throughout Metrics, including:

- data-platform architecture and ownership;
- naming and modeling conventions;
- warehouse tables and dependencies;
- dimensional and metric definitions;
- source-specific processing;
- planning and intelligence models;
- application and design-system architecture.

Claims about the warehouse must be verified against current Dataform definitions. Product terminology and workspace boundaries follow the current Metrics initiative in Linear.
